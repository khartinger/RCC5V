# 1. What is this about?

This directory contains information about the **RCC software** and **ESP32 programs** for different hardware configurations.

- [Demo software Version 1](https://github.com/khartinger/RCC5V/tree/main/software/rcc_demo1) – everything in one file
- [Demo software Version 1a](https://github.com/khartinger/RCC5V/tree/main/software/rcc_demo1a) – split into several files
- [Demo software Version 2](https://github.com/khartinger/RCC5V/tree/main/software/rcc_demo2) – with additional control blocks

Further examples include **ESP32 programs for various railway modules**.
